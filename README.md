# My Portfolio

## Features
- Responsive Portfolio Website
- Home Page
- About Page
- Projects Section
- Photography Section
- Research Section
- Contact Page

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Sadbin663/My_Portfolio.git
```

2. Open the project folder:

```bash
cd My_Portfolio
```

3. Open `index.html` in your browser or use Live Server.

## Usage

Navigate through the website using the navigation menu.
